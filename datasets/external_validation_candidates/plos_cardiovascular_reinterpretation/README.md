# PLOS Cardiovascular Variant Reinterpretation Cohort

Source article: Fernandez-Falgueras et al., *The importance of variant
reinterpretation in inherited cardiovascular diseases: Establishing the
optimal timeframe*, PLOS ONE 2024.

- Article: https://doi.org/10.1371/journal.pone.0297914
- Supplement: `pone.0297914.s001.xlsx`
- Supplement SHA-256: `79eae13f642c14ddadbef5913728745a32315f0164d1f3b6be8ded8e3dd5fbce`
- License: CC BY, as stated by the article.

The spreadsheet contains 1,261 listed variant rows with original and updated
five-tier classifications plus applied ACMG/AMP criteria. After restricting to
the current CardioQueue gene panel and B/LB or P/LP updated classifications,
197 unique gene/cDNA records remain: 94 B/LB and 103 P/LP across 38 genes.

The file does not provide genomic coordinates or transcript accessions.
Transcript-aware HGVS normalization and reference-allele validation are
therefore required before any record can enter an evaluation manifest. The
source must remain a distinct cohort and must be deduplicated against all
development and held-out sources.
