# CardioQueue research project

CardioQueue is a CatBoost-based research system for prioritizing inherited-cardiac-disease variants for expert evidence review. It produces a ranking score and research worklist; it does **not** assign ACMG/AMP classifications and is not a stand-alone diagnostic or treatment tool.

For a complete project orientation, current scientific status, repository map, data boundaries, and recommended next steps, begin with [`PROJECT_HANDOFF_FOR_ARVIN.md`](PROJECT_HANDOFF_FOR_ARVIN.md).
