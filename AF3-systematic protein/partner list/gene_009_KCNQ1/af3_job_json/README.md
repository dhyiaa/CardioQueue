# KCNQ1 AF3 Job JSONs

Default upload file:

```text
AF3_SYS_gene_009_KCNQ1_TOP3_upload_alphafoldserver.json
```

This file contains three jobs:

1. Tetrameric KCNQ1-KCNE1-CALM1-Ca IKs regulatory complex.
2. KCNQ1-KCNE1 full-length pair control.
3. KCNQ1-CALM1-Ca full-length pair control.

The first job is a systematic upgrade from the older pilot-v2 single-chain complex. It is biologically closer to IKs assembly but still lacks membrane, voltage-state, and PIP2 context. Held sensitivity jobs are listed in `AF3_SYS_gene_009_KCNQ1_not_generated_jobs.tsv`.
